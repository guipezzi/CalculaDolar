## 📖 Sobre o projeto

O **CalculaDolar** é uma aplicação web que realiza a conversão de valores em **Real Brasileiro (BRL)** para diferentes moedas internacionais de forma simples e rápida.

O projeto foi desenvolvido com foco em praticar conceitos fundamentais do desenvolvimento Front-end, como manipulação do DOM, eventos em JavaScript, formulários e estilização responsiva utilizando apenas tecnologias nativas.

---

## ✨ Funcionalidades

- 💵 Conversão de **Real (BRL)** para:
  - 🇺🇸 Dólar Americano (USD)
  - 🇪🇺 Euro (EUR)
  - 🇬🇧 Libra Esterlina (GBP)

- ⚡ Conversão instantânea
- 🎨 Interface limpa e intuitiva
- 📱 Layout responsivo
- ✔️ Validação do valor informado

## 🚀 Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/CalculaDolar.git
```

Entre na pasta:

```bash
cd CalculaDolar
```

Abra o arquivo:

```text
index.html
```

Ou utilize a extensão **Live Server** do VS Code.
